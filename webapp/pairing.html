Pairing help

This page only explains the steps. It never touches keys: key agreement and message encryption live in firmware (Rust), never in the browser or in any Python on this host.

  1. On board A, export an offer (TUI: /pair offer; app: Pairing → Offer; webapp: ask the operator running the bridge).
  2. Carry the QR image to board B and import it under a local display name (1–32 chars). Repeat in the other direction with a proof, then a confirm.
  3. SAS compare reminder: read the fingerprint / SAS transcript aloud on BOTH sides and only type YES when both operators see the same string. A mismatch means stop — do not confirm.
  4. Send a test message. Look for the ✓✓ tick (firmware ACKNOWLEDGED). ✗ means UNCONFIRMED: peer off, radio off, or out of range.

Radio stays on the fixed +2dBm profile; there is nothing to tune here.
